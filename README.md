This repository is the [Upptime](https://upptime.js.org) status monitor for **Hour Terms** — the self-hosted freelancer workspace for Kirby.

It checks the Hour Terms marketing site and the license / update / delivery backend on a schedule using GitHub Actions, records the history here, and publishes a public status page via GitHub Pages. No server required.

**Status page:** <https://joegullo.github.io/hourterms-status>

Once the workflows have run, this README is automatically rewritten with a live uptime table. What's monitored is defined in [`.upptimerc.yml`](./.upptimerc.yml).
